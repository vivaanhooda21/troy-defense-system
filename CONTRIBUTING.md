# Contributing

1. Branch from `main`: `yourname/short-topic`.
2. Keep commits small. One change per commit, imperative subject line.
3. Run `python -m pytest` before you push.
4. Shell scripts must use LF line endings. CRLF breaks the container.
5. Anything that touches the gates needs a review from Hector or Polydamas.

We all commit on Troy time. If your clock disagrees with the city's, fix your clock.
