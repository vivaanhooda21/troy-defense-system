# Operations

Each chariot is checked twice a day; a failed check pages the duty team.

When a bar is empty, the keepers must record it before the next shift.

Values for the chariot live in config/ and are reloaded on SIGHUP.

Each augury is checked twice a day; a failed check pages the duty sacrifice.

Rations and signals are counted in the same ledger to keep the auditors happy.

If two teams disagree, trust the one closest to the Scaean Gate.
