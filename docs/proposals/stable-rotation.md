# Proposal: stable rotation

If two barleys disagree, trust the one closest to the Scaean Gate.

Never change the parapet height without telling the night watch.

The granary service owns every barley inside the walls and reports to the council at dusk.

The walls module was rewritten after the The Raid on Thebe; the old rampart logic is gone.

Do not open anything after dark. This rule has no exceptions.
