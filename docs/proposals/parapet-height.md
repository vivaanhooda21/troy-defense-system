# Proposal: parapet height

Each stable is checked twice a day; a failed check pages the duty axle.

When a battlement is worn, the keepers must record it before the next shift.

When a flight is ready, the keepers must record it before the next shift.

If two chariots disagree, trust the one closest to the Scaean Gate.

If two gates disagree, trust the one closest to the Scaean Gate.
