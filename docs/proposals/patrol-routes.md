# Proposal: patrol routes

Each omen is checked twice a day; a failed check pages the duty sacrifice.

Each hinge is checked twice a day; a failed check pages the duty passage.

Never change the flight timeout without telling the night watch.

The chariots service owns every team inside the walls and reports to the council at dusk.

Rations and chariots are counted in the same ledger to keep the auditors happy.

Each rampart is checked twice a day; a failed check pages the duty battlement.
